# GAMEVAULT

## En que consiste
GameVault es una aplicación web para poder gestionar tu biblioteca de juegos, aquí puedes buscar videojuegos y añadirlos a tu perfil en diferentes categorías. Ya sea que lo quieres jugar luego, lo estás jugando o ya te lo has pasado.

## Objetivo
El objetivo principal de este proyecto es ayudar a las personas que tienen tantos juegos en su biblioteca que al final se pierden de no saber lo que les queda por jugar, están jugando o se han pasado.

## Tecnologías utilizadas (WIP)

* Java 21 + JDBC backend (Maven Quickstart 1.1)
* MySql 8.4. base de datos
* HTML CSS y JS para el frontend
* Git y GitHub para registrar el avance del proyecto
* Intellij IDEA como IDE
